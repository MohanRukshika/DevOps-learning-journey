# 🌿 Git Fundamentals — Lesson 01

## 📖 What I Learned

Today, I started learning Git as part of my DevOps journey.

### 🔍 What is Git?

Git is a distributed version control system that tracks changes in files and helps developers collaborate on projects.

### 🛠️ Git Commands Practiced

| Command | Purpose |
|---|---|
| `git config --global user.name "Mohan Rukshika"` | Set my Git author name globally |
| `git config user.name "Mohan Rukshika"` | Set my Git author name for the current repository |
| `git init` | Initialize a new Git repository |
| `git status` | Check the status of files |
| `git add filename` | Stage a file for committing |
| `git commit -m "updated this file"` | Commit staged changes |
| `git log` | View commit history |

## 🔄 Basic Git Workflow

```text
Working Directory
       |
       | git add
       v
Staging Area
       |
       | git commit
       v
Local Repository
```

## 🎯 Key Takeaways

- Git helps track changes in projects.
- `git init` initializes a Git repository.
- `git status` shows the current state of files.
- `git add` prepares changes for committing.
- `git commit` records a snapshot of staged changes.
- `git log` displays previous commits.
